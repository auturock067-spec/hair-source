# PENG Hair Sourcing

Independent English-first Chinese/English buyer reference for six hair-product sourcing groups. Public name is provisional; internal repository hair-source. No affiliation with Hairsource Atlanta / hairsource.net.

Home Laptop only: D:\AgentForge\hair-source. GitHub is the source of truth. Never overwrite another device’s commits.

Node 24. Run `npm ci`, `npm run build`, `npm test`, `npm run test:browser`. Preview: `npm run dev` (default port 4173; use PORT=4175 beside other projects). Runtime has no paid dependencies, API, database or secrets.

Includes search/filter, bilingual notes, six original construction SVGs, official quality/traceability references, local RFQ with units and truthful no-submission status. RFQ fields are not persisted; only language preference is stored.

This is a noindex draft preview, not a verified-supplier directory or storefront. No products, pricing, samples, test reports or ethical audits are verified. Keep Draft PR and preview until acceptance; production indexing/domain changes need review. See docs for research, specification, acceptance and deployment evidence.
